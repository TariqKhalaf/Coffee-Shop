# ☕ Coffee Shop Website

A modern and fully responsive promotional website for a Coffee Shop, designed to deliver a smooth and visually appealing user experience across all devices.

## 📸 Overview

The website provides an elegant and modern interface to showcase coffee menu items, brand story, customer testimonials, and a direct contact form. It features a responsive dark-themed aesthetic with warm accents tailored to complement the atmosphere of a premium coffee shop.

### 🌟 Features

* **Fully Responsive Design:** Optimized for seamless display across mobile devices, tablets, and desktop screens.
* **Smart Navigation Bar:** Features smooth scrolling and dynamic active-state highlighting for menu items.
* **Interactive Menu Section:** Clean product cards highlighting coffee selections alongside an "Add to Cart" action button.
* **Testimonials Section:** Stylish card layouts displaying customer reviews and feedback.
* **Contact Form:** Integrated input layout for direct customer inquiries.

## 🛠️ Technologies Used

This project was built using the following technologies and libraries:

* **HTML5:** Semantic markup structure with built-in accessibility.
* **CSS3 & Custom Properties:** Custom styling, CSS variables, glassmorphism effects, and hover transitions.
* **Bootstrap 5.3.2:** Grid system layout and responsive component utilities.
* **JavaScript (Vanilla JS):** Event handling for navigation link states and interaction.
* **Font Awesome 6.5.1:** Modern iconography for UI enhancement.
